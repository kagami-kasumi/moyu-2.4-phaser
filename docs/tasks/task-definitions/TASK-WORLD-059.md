# TASK-WORLD-059 · 安全区域进入恢复与储备补充

## 目标
玩家进入现有四个安全区域时，存活人物与出征幻兽恢复生命，人物魔力和生命/魔力储备补满，死亡幻兽仍需管理员复活。

## 输入
依赖TASK-PET-058；4536/frame1 dangerous完整函数及roleUnit绑定，frame8/9/10/12安全调用，RoleMC储备setter与HuanShouMC生命归属；已实现合体、铃铛、完整存档和管理员复活。选择理由：补齐当前养成/治疗旅程的安全区域恢复缺口。

## 范围
现有四区域初次进入与合法跨图；两职业、三槽、合体/死亡/空槽、生命和魔力储备上限与铃铛；拒绝未知归属或数值的部分写入。存档恢复保留保存现场，不能借加载回放恢复事件；不得增加每帧回血或假战斗。

## 输出
有界源合同、纯恢复规则和地图消费、用户可见恢复反馈、独立oracle、浏览器与保存证据。

## 验收
完整dangerous函数独立执行和安全地图枚举；存活/死亡与三槽/合体/铃铛/两职业、非法跳图原子性、无持续回血；正常新建成长跨图储备补充，受控受伤/死亡及实际存取；typecheck、npm test、build、check:save、专项、城内旅程/复活浏览器回归、截图、generate:harness/check:harness。

## 停止与拆分
战斗伤害/野外地图独立后续；本任务不实现那些入口。未知对象与上限保留原数据并拒绝恢复。
