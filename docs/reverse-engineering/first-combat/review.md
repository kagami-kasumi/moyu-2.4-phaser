# 首战集成评审

范围：TASK-WORLD-064；原SWF保持只读，无Flash执行层。检查沿源哈希、时间轴、像素、规则/显示分离、存档与真实玩家旅程进行。

已修复发现：

- P1：合体或幻兽铃铛反弹若先击杀敌人、升级回血，原先批量返回的生命写入会覆盖同步回血。`party-incoming-hit.ts`与`pet-world-combat-rules.ts`增加即时读写端口，剩余元素使用更新后的生命及上限；`first-combat-live`验证10伤害→升级到100→风3/火4后93。
- P1：安全区保存若递归合并旧扩展，会把上一野外的combat留在档案。`save-game.ts`离开战斗后明确删除旧实例；源波次死亡/收益不复播，保存与重入专项验证。
- P2：高级宝石不能走纯literalItem工厂。改用已源验证的参数宝石工厂；龙怪奖励仍由完整source oracle验证，不截掉稀有分支。
- P2：受击原函数会在无目标时锁定攻击者，幻兽死亡还消耗random(2)并清目标。`FirstCombat`补齐人物/宠物/怪物归属和死亡随机顺序；集成重跑通过。
- P2：原`priseExp`在持有卡萨诺郊区产权时另授经验值×20资源。接入实时产权端口；装备灵性后刷新属性，专项验证18经验/360资源与灵性升级。

独立性：伤害/AI/攻击/随机奖池测试执行原AS函数或冻结独立数据，不从生产实现反推期望；动作和图片同时检查独立FFDec XML/PNG。首战任务另执行原catchThing、taskComplete、nextMainTask逐杀对照两职业。
