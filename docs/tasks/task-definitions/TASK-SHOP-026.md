# TASK-SHOP-026 · 城内药店与采购使用闭环

## 目标

玩家点击卡萨诺城一药剂师，购买当前开放药品、使用或出售，并保存恢复全部交易结果。完整覆盖七种药品的共同采购机制。

## 输入

- 依赖 TASK-SHOP-025 的普通交易、TASK-ITEM-023 药品使用和既有完整存档。选择理由：当前城内已有药剂师图像，药品使用已实现但没有正常采购来源；该能力可独立交付且直接补齐当前旅程。
- 4536/frame9:7 药剂师位置155,280；4536/frame1:187 注册cmd19；4312/frame1 case19/20 打开 drugShop/backPack。
- 根frame9 drugShop实例2089/depth1448（必须复验）；frame9/DoAction_2:200–203 七条目录、初始openNumber2；1486/1952 持久drugShop。
- 4536/frame31/39/53 进入树心城/戈壁/沼泽至少开放4/6/7，当前地图尚不可达；只对受控数据验证这些目录，不提前开放区域或伪造升级入口。
- frame9/createThing 药品完整hpVal/mpVal/售价字段；既有药品源oracle与扣除机制。

## 范围

复用共享商店规则，保持杂货正常入口和开放数；药店有独立目录、选择、开放数与生命周期。七种药品全部精确源对账；正常只开放前两种。支持数量、取消、余额不足、满包、整格出售、购买后正常使用、存取及旧raw字段推广。

## 输出

docs/reverse-engineering/pharmacy/ 源合同、冻结目录/绑定/哈希、字段和验证；正式领域/面板复用、NPC入口、保存、逻辑/浏览器检查。

- 两职业无probe新建→实际进城→药剂师→购买→使用→出售/余额→保存、刷新和真实导入恢复；受控缺血/缺魔验证作用、完整目录、不足、满包和旧按钮拒绝，实际查看截图。
