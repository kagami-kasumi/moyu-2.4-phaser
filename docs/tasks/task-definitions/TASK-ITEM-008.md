# TASK-ITEM-008 · 背包物品使用与装备

## 目标
玩家从现有背包选择物品并使用，穿戴、替换和卸下装备，看到实际数量、装备槽与角色属性变化。

## 输入
- 用户指定下一任务为背包物品使用与装备；UI 可自主设计，保留已有原版 HUD。
- `local-resources/moyu/source-index/as/scripts/frame_9/DoAction.as` 的 useItem、equipment、backPack、createThing；`__Packages/RoleMC.as` 的属性计算；技能和幻兽加入函数按直接依赖窄读。
- 现有 NPC 礼包、完整新建物品、HUD 证据与运行工程。

## 范围
- 有界取证、实现与验收一体交付：现有新建/首次奖励中的直接消耗物（货币包、三类材料礼包、幻兽蛋、技能书、勋章），装备穿戴/替换/卸下与属性更新。
- 保留未开放独立系统物品，明确说明使用条件，不吞物品；经验球分配、地图传送道具、打造、社交、幻兽战斗/培养、实际技能战斗和存档不在本任务。
- 装备覆盖现有可获得的四类战士装备与戒指；职业/等级限制、满包溢出和切图保持是直接依赖。新交互为 design，不要求提取原装备面板外观或实现换装动画。
- 写入源证据目录 inventory、纯领域模块、背包/装备视图、必要输入和 HUD 接线、测试与本任务治理文件。

## 输出
- `docs/reverse-engineering/inventory/source-contract.md`、冻结源函数与验证报告。
- 可使用的背包、装备槽、属性反馈；独立源 oracle 与真实浏览器验收。

## 验收
- 独立源函数核对数量扣减、礼包入包顺序、满包溢出、幻兽容量、技能重复学习与装备限制/替换/卸下/属性。
- 冷启动真实点击完成货币包、材料包、孵化、学习及老兵装备领取—穿戴—卸下；切图/关闭重开保持；非法操作不丢物品。
- `npm run typecheck`、`npm test`、`npm run build`、`npm run test:browser`；必要源证据检查与既有资源回归。保存截图并检查布局与操作反馈。
- 状态变化运行 `npm run generate:harness`，收尾 `npm run check:harness`。

## 停止与拆分
不因耗时或上下文压缩停止。关键源事实不明时继续有界调查，不猜测。只有实际缺少原始材料或外部依赖才记录阻塞；独立系统留待后续任务，不伪称实现。
