# TASK-WORLD-069 · 卡萨诺幻境战斗与奖励旅程

## 目标

玩家消费城二首次赠送的卡萨诺幻境，打败四只幻影龙怪，获得并使用原奖励、返回城二；支持中途保存恢复、自然随机进入和一次性结算。

选择理由：068已补齐元帅奖励挑战，城二首次幻境仍是当前区域的直接未闭合奖励。frame11只有四只5级龙怪，沿用已核验的龙怪普通/技能时间轴，适合当前卡萨诺角色自然挑战，不依赖高阶测试装备。

## 输入

TASK-WORLD-068及067自然档；city-second首次赠送、计时源合同、既有FirstCombat与龙怪技能攻击。原4536/frame11、frame10、frame1的initMonster/monsterDeath/ dropItemX/SuperHS/maxArr、4247出口行为及root/frame9地图道具消费工厂。独立XML frame11使用4328背景、2803/2802地面，entry6位置(294.95,317.6)。

已发现源异常：道具与随机进入指定不存在的entry1；frame11隐藏entry6，死亡末怪却显示不存在的entry1。必须进一步核验独立XML/AVM1行为并明确记录现代修复，不能冒充原版可用出口。SuperHS引用未形参化的fX/fY，须追踪其真实可用性。

## 范围

卡萨诺幻境地图、四怪真实攻击/技能及击杀奖励、20%四种超级幻兽蛋、同图使用拒绝、末怪结算一次、清怪后回城、死亡、完整存档。dropItemX级别0仅random(4)：0/1无物、2九玫瑰、3极品玉石；不得误开放其他级别奖励。奖励取得后走现有消费者（幻兽孵化/养成、既有兑换/打包或出售奖励用于补给），不能只证明持有。

在取证确认原缺失入口后，可采用明确design修复：使用实际entry6作进入落点，四怪清空显示实际entry6返回城二；未知掉落坐标使用显式现代安全落点，不伪称源坐标。城二随机条件保留严格小于intoV与等待大于300000，暂停/恢复计时语义单独标注，恢复不能重发首次道具或随机重进。

不扩展六个其他幻境、后续城市、主动技能或所有终局装备来源。

## 输出

独立源fixture/oracle及合同、正式地图/战斗/奖励/随机进入/存档消费者、UI、真实两职业旅程与边界检查、验证评审和覆盖台账。

## 验收

独立原生成与死亡函数覆盖两职业、普通/技能、四个dropItemX分支及SuperHS概率/四蛋、随机调用顺序、最后一只判断；原入口缺失由XML与脚本交叉确认。碰撞、落点、物品消费、重复回调、满包、死亡回城、部分清怪和清空存取、随机进入阈值与首次奖励幂等。

两职业从当前自然档用真实输入四怪通关，拾取并实际消费奖励、返回城二、保存刷新与文件导入。随机未落蛋不得伪造自然结果，可重复新建正常进城获门再挑战，另受控强制分支覆盖；不得用kill替代正常旅程。
