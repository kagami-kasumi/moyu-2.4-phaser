## 实现选择（design）与未覆盖

网页新建/男战士/姓名入口保留源步骤与校验，用现代 HTML 控件；NPC名字使用系统中文字体，不宣称旧嵌入字体像素一致。原界面的背包快捷栏、货币、任务弹窗、教程购物文字、随机NPC、初始幻兽及其战斗跟随系统不在此旅程的操作依赖内，不实现相应系统或假按钮。地图资源、角色动作与可见常驻NPC单独比对，不把完整原屏幕当成本切片的验收声明。

浏览器失焦/隐藏时释放输入并暂停逻辑时钟，避免后台积累移动（design）。动作验收页保留独立入口。到达城一后显示本次切片完成；重试使用网页刷新重新新建，不虚构原版重试按钮。未开放的出口告知切片边界，不进入无证据场景。

## 实现前冻结的操作与异常预期

1. 冷启动依次新建、选择男战士、输入名字、进入。空名不能进入；角色脚点应为 `(277.8,421.6)`。
2. 按右5次 Activities 到 `(337.8,421.6)`，松开后一次 Activities 保持坐标并站立。向上13步到 `(337.8,304.6)`，再向右16步到 `(529.8,304.6)`。仅停留不切图；按 Q 后到城一 `(42,306.6)`，一次成功切图。
3. 同一路径可由地面按住鼠标完成；松开停止。鼠标按住期间到达 entry2，再在该入口松开可触发一次切图。
4. 出界时按源逐候选碰撞/滑移规则处理；城一斜边要测试矩形范围内但多边形外的点。覆盖描边与 root 比例。
5. 远离入口按 Q、入口隐藏、入口 alpha=0、nextMap/标签不匹配都不能成功切图。入口 alpha=0 不等于不可捕获地面输入。成功到达后持续逻辑步进/按住 Q 不增加成功计数。
6. 15/30/60/144 Hz 调度、长帧、页面隐藏恢复与刷新冷启动都须验证；运行只加载 public 中正式资源。

## 基准说明

baseline/ 的14张 PNG由 FFDec 26.0.0 直接导出 selected shape；现代 actual 直接解析二进制标签、JPEG/Lossless、路径和矩阵。两张背景及七张NPC须逐像素一致；JPEG3亮环允许不同 JPEG/反预乘舍入导致单通道1级差异；地面斜边允许 Java2D/libvips 描边抗锯齿差异（平均预乘误差<0.03/255），不放宽几何坐标。浏览器另以这些冻结图片和 XML 矩阵独立 Canvas2D 投影对照 Phaser。行为 expected 使用冻结源 AS 函数的受限离线 JS 语义执行，不使用现代规则产生 expected。
