# TASK-EQUIP-028 · 装备宝石镶嵌与拆取闭环

## 目标

玩家将宝石镶入已有装备孔，看到对应装备/人物属性变化，付费拆回可再次使用的宝石，并能保存恢复装备与拆取槽。

## 输入

依赖TASK-EQUIP-027及已完成开孔、杂货交易、注册和存档。选择理由：现有开孔和采购经验宝石已经可用，孔内效果与回收仍缺失；完整镶嵌→属性→拆取再用是当前物品机制缺口。

精确源入口为local-resources/moyu/source-index/as/scripts/frame_9/DoAction.as：makeItem约3518的11种宝石分派，3930附近寻找首个空孔并写holeN/gemN/gem(10+N)，useGem/yesButton约3343；equipment.flashAttribute约1987及2080的七种孔类型聚合；splitStone约4146–4300的选择、计价、beginSplit与回收。DefineSprite_4312/frame_1/DoAction.as:约650–709对话cmd92/93/94为打造/拆取入口。frame_9/DoAction_2.as:1203起为splitStone持久字段，既有save注册可消费。

已有equipment-magic/source-functions.json冻结makeItem/useGem/yes；须新增独立splitStone与属性函数冻结及AS/P-code核对，不覆盖历史提取。任务内部确认NPC身份/当前地图可达性、按钮绑定及拆取剩余分支后实现；新面板视觉为design，未证实入口不宣称原版。

## 范围

两职业四装备、1–3孔；中/高级战斗力、攻击、减伤害、经验宝石与战斗攻击/减伤害/经验圣石11命名类别及注册参数变体。保留首空孔顺序、装备类别限制、材料扣除、七类孔效果和三个拆出槽所有权。拆取按实际占用孔计费，已有拆出物先返回背包，满包按源落地；精确保留孔清理与残留gem字段行为。

完整验证属性聚合消费者（战斗力、攻击、减伤、经验）与现有技能/品质/魔魂组合；未存在的战斗系统不为此虚构。保存/迁移splitStone装备和三材料槽，未知raw继续保留。非法对象、空孔、满孔、余额不足、取消、旧回调、切图与新建均有边界。神力、魔之魂、元素、戒指/幸运符升级不含本次。

## 输出

独立源合同/冻结函数/字段归属/验收，镶嵌与拆取领域模块和可操作UI、人物属性集成与保存推广、覆盖台账、逻辑和浏览器测试。

## 验收

- 源oracle对照11类别×适用/不适用装备、孔数/占用布局、0/1/堆叠材料及参数变体，比较完整装备、消费和属性；拆取按孔位计价、还原名称/售价/参数及重入旧输出槽，与源完整比较。

- 余额不足、满包溢出回收、重复按钮、切图/新建、保存刷新、真实导出导入、旧raw推广及未实现字段无损均通过。

## 停止与拆分

正常逆向、多个材料/孔位与界面是本机制内部里程碑，不拆成逐宝石任务。仅实际文件/工具缺失或必要用户裁决可阻塞，未知效果先取证；远区材料获取与其他打造能力另列后续，不将其标记完成。
