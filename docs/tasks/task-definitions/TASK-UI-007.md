# TASK-UI-007 · 还原原版HUD与已实现功能入口

## 目标
默认游戏页面呈现原版580×500舞台的主界面，并可从原版位置操作已有背包、幻兽记录和老兵对话。

## 输入
根时间轴帧9，rolePanel/4591、battleHuanShouPanel/4556、fastKey/4546、底栏按钮2619–2655、XP/4603、地图栏4592；背包2074、对话2293。精确AS入口在local-resources/moyu/source-index/as/scripts，显示列表为同目录上层source.xml。已完成礼包和地图证据在docs/reverse-engineering。

## 范围
任务内部完成原版HUD显示列表/可见性/初值/按钮脚本取证，离线资源转换，主界面和已有功能入口还原及浏览器验证。包含角色/初始凯恩头像状态条、XP格、底部快捷栏与导航、地图信息，背包40格与对话原版布局。未实现系统入口如需保留原画面，明确不可用，不假装已实现。战斗、物品使用、成长和存档不在此界面任务实现；动态数值必须来自verified初值或真实状态。原SWF与旧提取物只读。

## 输出
有界源合同与独立源基准、正式UI资源及生成/核验工具、分层HUD适配器、原版布局入口、逻辑和浏览器检查及验证报告。

## 验收
类型/逻辑/构建/harness检查通过；新增check:original-ui检验原资源与冻结源显示列表、初值/关键脚本；Edge冷启动可见HUD与源基准对照，主界面/背包/老兵对话截图，真实入口开关、礼包领取后40格内容、鼠标不穿透、Esc和键鼠回归。默认运行仅使用正式资源，不依赖原SWF。既有独立地图/角色/礼包验证继续覆盖。

## 停止与拆分
关键UI证据缺失时继续精确取证，不以现代仿制替代原版资源。未实现系统不作为已实现功能；实际外部阻塞需记录已尝试路径。完成范围为主界面与已实现功能入口，不声称完整游戏。
