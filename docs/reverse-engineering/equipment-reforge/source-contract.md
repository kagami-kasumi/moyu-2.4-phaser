# 高阶重铸源合同

verified：makeItem四装备分支3631–3677灵魂王与3911–3914神力宝石，复用equipment-magic冻结的makeItem/useGem/yes/upDataWeapon及AS/P-code哈希。P-code14685起grade<4先useGem再加品质；grade4/5先检查声望，useGem(5/10)成功后才扣20/50声望、升品质、发消息。失败可能先发“宝石数量不足！”再发“需要5/10个宝石。”；数量0按非堆叠单件语义。神力宝石先写levels=1后useGem，即使原为1仍消费成功。成功按钮统一重算，材料空时另发“装备打造成功”。没有随机抽取。

upDataWeapon重算名称、基础攻击/防御、魔魂属性、元素最低值、价格；更高元素数值保留，孔/战魂/未知字段不抹除。神品魔魂之心上限38，上神品50，按既有已验证模块消费。

design：单独“高阶重铸”模式限制四装备，避免误送戒指/幸运符不同规则。材料选择与成本解释无虚构供应：神力宝石杂货目录16已注册但初始只开4，灵魂王获取未开放。因此本项材料旅程为明确受控输入后真实UI、保存导入，普通UI仅显示真实缺材。
