# TASK-SHOP-044 · 城三幻兽商店交易与孵化旅程

## 目标
玩家在城三幻兽商处购买当前开放的幻兽蛋、孵化或出售并保存恢复；完整20货位有源定义和开放档位约束。

## 输入
依赖TASK-WORLD-043。选择理由：城三已提供自然NPC入口，商店可复用2089交易规则，已实现固定种子孵化可消费19种商品；补齐该区域直接可玩的交易旅程。frame_9/DoAction_2的huanShouShop目录20项、openNumber9和levelNum[0,9,11,14,17,20]；2089商店完整函数；4312 cmd101/102；4536/frame12；frame9 createThing/useItem，既有ordinary-shop源oracle、item-pets与保存huanShouShop字段。

## 范围
全部20货位交易与档位门槛，初始9项自然可购，复用逐格出售/数量/满包掉落与扣款顺序；三商店隔离、旧档货位推广、两职业购买固定种子孵化并跨图保存。后11项由旧档或受控测试验证，商人升级另一个完整任务。奇迹龙随机孵化若尚未实现须明确显示暂未开放，不把购买等同孵化或战斗；本任务不扩展幻化/合体/战斗。

## 输出
20项源目录和独立交易证据、幻兽商店领域/UI/持久化、两职业正常购买孵化旅程及回归报告。

## 验收
- 独立源数组/AS与P-code哈希/2089绑定；全20项工厂字段、数量1/3/99、空槽/满包/不足、逐格出售与完整源oracle对照；档位9/11/14/17/20及旧回调、切店/切图/新建。
- 两职业无probe城三购买凯恩/莎菲/奇异兽、孵化固定种子/出售、跨图、保存刷新与真实文件导入；受控全目录/满包/缺钱/末级货品反馈。保留原商店与城三回收回归。
- typecheck、npm test、build、check:save、test:browser及generate:harness/check:harness，查看截图。

## 停止与拆分
这是交易能力完整交付，不按目录/领域/UI拆任务。商人四阶段升级具有独立任务受理/资助/领奖生命周期，留后续；随机孵化不以固定种子伪造。仅真实缺失源输入可阻塞。
