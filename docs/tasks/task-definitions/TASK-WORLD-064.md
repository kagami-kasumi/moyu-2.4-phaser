# TASK-WORLD-064 · 卡萨诺城野外一首战与返回旅程

## 目标

两职业从郊区进入卡萨诺城野外一，完成六只鹿角兽所构成的可重返战斗区域，获得原版战斗收益并安全返回；受伤、死亡/复活、掉落与保存恢复形成真实闭环。

## 输入

依赖TASK-WORLD-063。已定位4536/frame8 entry1→野外一entry2；frame7 entry2→郊区entry1、dangerous(true)、initMonster(1,6)和六个固定坐标、1级鹿角兽与全部参数，entry1指向野外二。进一步在本任务内读取4536/frame1的initMonster、monsterDeath/dropItem和逐帧调度、__Packages/MonsterMC.as的Activities/攻击/受伤/死亡、RoleMC/HuanShouClass的相关命中与目标选择，以及source.xml对应鹿角兽和玩家时间轴。复用content-registry/pet-world-semantics.md、pet-world-combat-rules.ts、world-drop-rules.ts及其独立源测试、现有动作/成长/安全恢复/存档合同。

选择理由：前两项基础及城市/王室区域已具备，郊区仍有已确认但关闭的危险区入口，当前玩家缺少可以消耗既有成长成果的敌人战斗。先交付一张完整危险区及其回城闭环，再按后续区域扩展，不以PK报名替代实际战斗。输入文件齐全；行为与命中时间取证在本任务中完成后才实现。

## 范围

野外一背景、地面、两入口与六怪初始化；鹿角兽完整必要动作/警戒/追踪/攻击/伤害/死亡与重入生命周期；两职业可以完成首战的源正常攻击、必要技能/幻兽接入与目标归属，逐项写明已开放能力；经验、任务击杀记录和完整原掉落分支、拾取/使用、受伤/死亡/复活与安全区恢复。刷新和文件导入恢复当前地图及游戏状态，瞬时战斗状态的处理必须从源调查并标明现代差异。野外二入口保持明确未开放；全世界敌种、全任务线和PK另有独立区域交付价值，不混入本包。

## 输出

独立源合同与时间轴/图像基准、完整野外一运行时、渲染与输入、可消费命中/收益规则、保存字段迁移、源对照/逻辑/浏览器验收和覆盖台账。注册数据已存在不能视为实时战斗已实现。

## 验收

独立XML/Action枚举地图与六怪；源函数对照全部本区AI状态、范围边界、目标优先级、攻击伤害、随机次序及奖励分支。命中时刻按实际动作和脚本核实，不从SWF声明15FPS直接推算。两职业无probe自然进入、攻击击败敌人、拾取并使用收益、回城和再次进入；受控覆盖六怪、两职业与出征/合体幻兽归属、死亡复活、满包、暂停/跨图/旧目标、不重复击杀奖励，以及战斗中/死亡后存取边界。执行typecheck、npm test、build、check:save、新增区域源检查、专项浏览器和相邻安全区域回归；转换/解析修改另check:source；generate:harness/check:harness。留截图、日志和真实导出档。

## 停止与拆分

同一首战旅程的取证、转换、实现与验证不按阶段拆任务。未核实伤害、目标或时间轴时继续有界取证，不能用猜测填入verified；只有实际缺失依赖才记录阻塞。其他区域敌人/任务与完整技能库可独立后续交付，但不得省略让本区两职业真实可战斗所必需的能力。
