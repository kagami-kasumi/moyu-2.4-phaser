# TASK-NPC-067 · 元帅爵位与军衔任务旅程

## 目标

玩家从皇宫元帅接到爵位/军衔任务，使用任务给予的行踪进入现有头目地图，在野外完成五龙怪精英与一龙怪头目目标，领取两类功绩和物品，看到晋升收益并实际使用风元素；全过程可保存继续且不重复计数或发奖。

选择理由：064–066已开放卡萨诺战斗、龙怪精英与头目和行踪消费，元帅的两项入门任务仍未接通。补齐这条城内接取→野外执行→奖励与晋升旅程，同时提供原版确定的行踪来源；不扩张为整个支线系统或新地图包。

## 输入

- TASK-WORLD-066的野外四/五、行踪消费、真实战斗击杀事件、完整存档链；TASK-WORLD-061的元帅菜单与功绩消费者，既有装备元素机制。
- 只读AS：DefineSprite_4312/frame_1/DoAction.as的cmd171/177–180，原爵位/军衔条件、确认/取消、接取和createThing行踪；cmd179/180仅检查isDoing，已完成后是否能重接必须与完整菜单可达性一起确认，不自行“修正”。
- DefineSprite_2210_任务系统/frame_1/DoAction_2.as第41/42行、正式quest:branchTask:0/1：军衔一龙怪头目→1000军功+幸运之门，爵位五龙怪精英→1000功勋+风元素。
- 同sprite DoAction.as的getTask/catchThing/taskComplete/getPrize，根frame9功绩字段setter及原存档branchTask0/1 doing/complete消费者。AS/P-code与独立Action作为冻结输入。

## 范围

完成两支线的元帅菜单资格、确认、接取、行踪发放及真实使用、目标与等级计数、完成/未领取/已领取、原逆序奖励和爵位/军衔实际收益。接到两项时必须并存，跨图、任务四与首头目链不能互相重置。明确战斗玩家/幻兽击杀怎样流入源catchThing；护卫/龙王不得冒充龙怪头目，普通龙怪不得冒充精英。

保存原doing/complete旗标和现代部分计数；旧原档无部分计数的限制如实保留，已保存高爵位/军衔不得降级或重复奖励。满包行踪/任务物品落地、取消、重复确认、旧NPC回调、死亡、刷新/导入与游戏新建均覆盖。

幸运之门奖励完整持有/保存与明确未开放提示；该道具的独立多波挑战区域不由本任务宣称可用，也不能吞掉它或造假传送。风元素通过既有装备元素界面实际消费。远区强盗、其他支线、PK和全主动技能排除。

## 输出

元帅支线源合同与冻结oracle、领域任务所有者、元帅与任务操作UI、击杀/奖励消费者、存档扩展、源/逻辑/浏览器证据及功能覆盖台账。

独立执行原菜单/接取/任务计数/领奖/功绩函数，对照两职业、资格各边界、全部领取顺序与满包随机消费。实际Journey连续覆盖同时接取、取消/重复、五精英跨波次累计、一首头目完成、两类领取、已完成/领奖后旧回调及不重复晋升。

两职业无probe正常接取→获行踪并使用→现有怪物击杀→领奖→风元素实际打造和晋升属性→保存/刷新/真实导入；保留截图与导出。受控补齐低/高既有爵位军衔、满包、部分旧档、死亡、未领/已领与不满足条件。

运行typecheck、npm test、build、check:save、新增元帅任务源核验、专项浏览器与palace及kasano-finale相邻回归、generate:harness/check:harness。修改原始源解析时另运行check:source。
