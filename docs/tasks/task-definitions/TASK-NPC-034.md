# TASK-NPC-034 · 城郊管理员资源与通行物交易

## 目标
玩家在卡萨诺城郊区管理员处出售资源、兑换两张地图和50级PK参赛券，看到扣款与入包/掉落结果，并保存继续。

## 输入
依赖TASK-EQUIP-033。选择理由：装备属性与保存消费者已扩展，当前城郊已有管理员可见角色，但资源与通行物交易尚未接入；以当前区域的完整交易入口推进下一段可玩旅程，避免继续按单个属性扩张。源DefineSprite_4536/frame_1/DoAction.as:207注册cmd3011；frame_8:8放置npc02于450,250。DefineSprite_4312/frame_1/DoAction.as:1586 case3011，1756–1832 case3103–3109，4314起case13111兑换50级券（不是13112的60级券）。背包useThing/createThing与角色spendRes/货币setter复用已有源基准并对本次分支独立冻结AS/P-code。

## 范围
当前地区四档资源出售：1000/10000/100000/500000换8/85/850/4250魔石；5灵魂晶石换亚维特岛地图、1魔魂之心换蜘蛛谷地图；5声望和888魔石换50级PK券。完整不足、扣除顺序、堆叠跨槽、满包与封顶。原版入口互动、交易结果、背包和保存；地图/券只是获得的通行物，不开放未实现地区或赛事。

## 输出
源合同、冻结/oracle、交易领域与管理员UI、保存验证、截图和覆盖台账。

## 验收
- 独立源枚举全部7种当前地区交易，比较余额/材料/入包/掉落/消息；阈值前后、声望先行、跨槽、满包、货币封顶和随机调用顺序。
- 两职业无probe：真实管理员入口、开局资源出售、礼包取得材料→兑换地图与券→保存刷新/真实文件导入；受控矩阵覆盖不足/封顶/满包。
- 旧按钮、关闭、切图/新建隔离，普通商店/药店/老兵入口回归；原raw和未实现字段保留。
- npm run typecheck、npm test、npm run build、npm run test:browser、npm run check:save与实际截图；generate:harness/check:harness。

本项是当前区域交易机制，不扩展其他地区管理员、产权/爵位购买、幻兽复活、地图使用或PK赛事。相关入口不得假装可用。实际输入缺失才阻塞，不因取证和UI步骤拆分。
