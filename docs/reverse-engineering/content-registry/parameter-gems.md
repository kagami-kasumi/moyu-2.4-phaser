# 带参数的宝石工厂

源入口：`frame_9/DoAction.as:4308` createThing。五个定义为高级攻击宝石、高级减伤害宝石、高级经验宝石、高级战斗力宝石和魔之魂。正式注册保留原条件表达式；`tools/lib/parameter-item-evidence.mjs` 在重建时执行原函数逐字段对照，测试入口为 `tests/parameter-item-source.test.mjs`。

只有输入type为“宝石”时，工厂从name确定宝石种类并读取val1/val2。直接以具体宝石名称作为type时，传入数值被忽略，两个局部参数保持0。undefined或null也转为0；数值0触发默认值，非零数值保留，包括负数。四种高级宝石默认val1依次15、8、25、5；魔之魂两个参数默认都是0。工厂不在此处限定正常游戏数值范围。

对照覆盖两种入口、缺省/null/零/正负数/NaN的组合，并检查完整输出字段；篡改价格会触发失败。该验证确认原源码声明和参数传递，不证明特殊值都能在正常游戏中产生，也不确认镶嵌效果。
