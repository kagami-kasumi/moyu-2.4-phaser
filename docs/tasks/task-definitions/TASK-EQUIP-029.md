# TASK-EQUIP-029 · 戒指品质与精炼闭环

## 目标

玩家将已有戒指提升品质，并用八类精炼材料在共享十级上限内提高指定数值，穿戴查看有效属性、保存并继续操作。

## 输入

依赖TASK-EQUIP-028。选择理由：当前新手戒指、新建debug戒指与幻魔/魔魂礼包材料均已正常可得，戒指打造仍被四装备入口拒绝；补齐现有物品的完整成长能力。

精确源为`frame_9/DoAction.as:3383–3511`的makeItem戒指分支、3343的useGem、yesButton与upDataWeapon戒指分支；`equipment.flashAttribute:2209`戒指按mainType/pairType消费。已有equipment-magic冻结makeItem/useGem/yes及inventory属性源函数，不覆盖旧证据；本任务独立核对并冻结戒指upDataWeapon与ringMainValue表、物品属性初始化、UI说明和存档字段。

## 范围

两职业已有戒指，灵魂晶石/灵魂王品质0–4；八类共享mhdj<10精炼：高级攻击/减伤/经验/战斗力宝石、幻魔之心、魔魂之心、玄铁矿、紫水晶。确认每种数值增量、重算对主副属性的覆盖关系、主副选择生效与潜在未激活字段。未知必须先取证，不将所有增量一概当作立即生效。

独立戒指打造UI或共享面板模式、独占装备/材料槽、属性显示和完整持久化；所有权与原make保存键兼容，不允许镶嵌/开孔等四装备操作误处理戒指。幸运符、锻造技能、宝石融合与远区获取不含本次。

## 输出

戒指源合同、字段归属、源oracle与验证报告；领域规则、可操作UI、保存/旧档接入、覆盖台账及逻辑/浏览器测试。

## 验收

- 对照源函数：两职业、品质0–4、mhdj0/9/10、十类材料、数量0/1/堆叠/不足、不同主副选择和完整字段；组合品质、精炼与穿戴人物公式核对。
- 两职业无probe正常领取礼包、现有戒指、幻魔/魔魂之心精炼→品质→穿戴属性→保存刷新/真实导出导入。其他材料受控矩阵，明确未开放获取路径。
- 空槽、错误类型、十级共享上限、全满背包回收、重复/旧按钮、关闭/切图/新建、旧raw和未实现字段无损。
- `npm run typecheck`、`npm test`、`npm run build`、`npm run test:browser`、`npm run check:save`及真实截图；`generate:harness/check:harness`。

## 停止与拆分

仅真实缺失输入或必要用户裁决可阻塞。品质与八材料属于同一戒指成长能力，不按材料或技术阶段拆分。保留源属性覆盖行为，不能为使强化看起来有用而改成设计数值。
