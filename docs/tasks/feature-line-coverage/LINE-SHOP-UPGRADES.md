# 杂货商升级覆盖

[TASK-SHOP-037](../task-definitions/TASK-SHOP-037.md)负责2–5级四阶段接受/资助/领取、对应货位解锁与任务/商人/库存持久化。需独立源全枚举、正常两职业全阶段、满包与旧回调、跨图存取关闭；其他商人升级与社交不在本线。

关闭证据：[源合同](../../reverse-engineering/shop-upgrades/source-contract.md)、[验证](../../reverse-engineering/shop-upgrades/validation.md)；四阶段64组源对照、90项全量浏览器和最终3项升级专项通过。
