# TASK-ITEM-013 · 灵魂晶石装备品质提升闭环

## 目标
玩家使用现有灵魂礼包获得灵魂晶石，将四类装备的品质提升至极品，取回穿戴查看重算攻防、魔魂加成、售价和战斗力；材料不足或到达晶石上限时不误扣。

## 输入
- TASK-ITEM-012 的共享打造双槽、强化规则、回收与完整对象源对照；TASK-ITEM-008 的灵魂礼包和穿戴。
- 根 `local-resources/moyu/source-index/as/scripts/frame_9/DoAction.as`：make.gradeSuccess（2881）为2/4/8/16/32/64/128/256；普通装备 makeItem 的灵魂晶石分支（3617附近）在grade<4时调用useGem(gradeSuccess[grade])，成功后grade+1；flashInfo、yesButton、useGem、upDataWeapon和equipment.flashAttribute；AS及P-code均已在现有冻结文件可定位。
- `frame_9/DoAction_2.as` 的品质名称（35）与装备名称；现有初始包有灵魂礼包，正常流程可获得晶石并升级原礼包装备。
- 选择理由：品质提升直接补齐现有灵魂礼包的使用旅程，与已完成开孔/魔魂共享装备，并能产生真实穿戴收益。灵魂王的神品/上神品分支涉及声望，留给单独可获得声望与材料的旅程，不用受控注入冒充可玩入口。

## 范围
有界逆向、独立冻结基准、四类装备灵魂晶石品质提升、现有打造面板扩展及显示修正。覆盖源grade 0–4边界和按当前品质的晶石消耗；升级后基础/魔魂攻防、元素底值、售价和装备战斗力重算，原孔/镶嵌/附加/战魂字段守恒。戒指、幸运符、灵魂王/声望、装备等级、镶嵌、战斗和存档不扩展。UI可现代重设计并标design，不将显示文案中的概率直接当作随机执行事实。

## 输出
`docs/reverse-engineering/equipment-quality/` 源合同、冻结期望、验证报告；领域与打造/背包显示扩展、逻辑与浏览器测试。
