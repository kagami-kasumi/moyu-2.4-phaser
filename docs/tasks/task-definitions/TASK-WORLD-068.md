# TASK-WORLD-068 · 幸运之门三十轮挑战

## 目标

玩家实际使用军衔任务奖励的幸运之门，进入挑战区，从六怪波次到第10/20/30轮首领、最终宝箱，取得并使用奖励、返回城内；中途存档继续不重置波次、不重复奖励。

选择理由：067完成任务奖励供应，幸运之门仍只有持有和未开放提示。补齐这条直接相连的挑战旅程，覆盖随机12物种而非为单个怪物另开任务。

## 输入

- TASK-NPC-067的自然军衔奖励导出、任务消费与已有FirstCombat/Journey；已实现物品生成、装备强化与幻兽成长。
- 原root/frame9/useThing幸运之门及createThing字段；DefineSprite_4536/frame162入口、homeCity出口、dangerous、testCount=1和3秒预警；frame1/encounter幸运之门分支、monsterDeath怪怪兽四名分支、initMonster、flashBs。
- 独立FFDec XML frame162：background4343、ground2807/2806、entry1(286,431.6)，完整显示列表与原地面轮廓必须核验，不能仅依据登记推断。
- 12物种选择鹿角兽/龙怪/骑士亡魂/巨猿/守卫魔/绿魔精/恐兽/提风/四牙怪/巨杰士/暗黑格拉斯/机关兽；4116对应selector和子时间轴、initialize/Activities/range与攻击效果。
- DefineSprite_4312/frame1的宝箱即时luckyBoss及去重生命周期，既有finale-chest核验可复用但须确认幸运之门绑定。

## 范围

正式挑战地图、行踪式道具消费/同图拒绝、12种源模型或明确design视觉投影（不能伪称原像素复刻）、30轮生成与预警、27轮六怪和3轮单首领、同步随机掉落、角色等级参与的逐轮数值、死亡/离场/重进、homeCity回城、宝箱。

源事实：普通怪物life倍率3，10/20/30首领倍率10/15/20；具体攻击、防御、元素、动态等级、经验和奖励必须通过源oracle核验后实现。保存testCount、当前波次敌人和预警是现代扩展，旧档缺字段限制如实记录。幻兽/人物击杀共用事件，不令怪怪兽冒充鹿角兽/龙怪任务目标。

不扩张其他挑战区、其他区域主线、社交、全主动技能。最终宝箱奖励通过既有消费者实际使用，不把持有当使用。

## 输出

源合同和冻结oracle、地图/视觉资源、挑战所有者与UI、掉落和存档、领域/源/浏览器验证、覆盖台账。

## 验收

独立执行12选择×30波次×多等级原生成函数；普通与三个首领奖励全部分支、随机顺序、3/10秒预警、31终点宝箱、动态升级后生成、不重复结算与旧回调。完整30轮领域旅程及跨波存取。

两职业从067真实奖励导入，无probe实际消费→首轮实战→离场回城→保存/刷新/导入。另使用明确标注的合法高阶装备/成长测试档，以真实浏览器输入打完30轮、开启宝箱、使用奖励并回城；测试档不宣称验证装备取得旅程。受控覆盖12物种、满包、死亡、暂停、同图拒绝、缺失旧字段和重入。保留截图与导出；不能用受控kill代替完整浏览器战斗。

执行typecheck、npm test、build、check:save、新增check:lucky-gate、专项浏览器及marshal-quests/kasano-finale相邻回归、generate:harness/check:harness；原解析器修改另check:source。

## 停止与拆分

未知关键数值/掉落/波次或出口继续窄查，不猜测；仅缺必要外部文件或用户裁决时Blocked。源取证、实现和验证均在本任务内，不能拆为三个完成项。

## 验收范围修正依据

实战准备发现源药店解锁依赖未开放frame31/39/53地区，当前卡萨诺段只有两种小药；068不能把这些城市及终局养成顺带宣称完成。调整验证分层：真实067道具来源和第一轮战斗保留，30轮完整机制使用显式受控高阶角色但实际控制战斗，装备来源另属后续地区/养成旅程。此修正不减少30轮、12物种、奖励与回城功能，也不把kill调用充当实战。
