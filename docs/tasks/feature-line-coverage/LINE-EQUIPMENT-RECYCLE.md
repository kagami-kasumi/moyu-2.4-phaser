# 装备回收覆盖

[TASK-EQUIP-042](../task-definitions/TASK-EQUIP-042.md)负责七类装备经验球兑换、四类装备分解、持有槽归属与存档、正常使用产物旅程。全部源组合及两职业浏览器验证通过才关闭；城三、铃铛生成和军功捐献属于后续。

范围完成：196组经验数量、26880组分解完整输出、源满包及生命周期、持有槽完整替换与未知元数据保留通过。两职业正常回收→成长/打造→三阶段文件导入以及106项完整浏览器回归通过；见[验证报告](../../reverse-engineering/equipment-recycle/validation.md)。
