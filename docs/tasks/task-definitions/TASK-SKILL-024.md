# TASK-SKILL-024 · 人物技能书学习与被动属性机制包

## 目标

玩家从背包学习人物技能书，在技能面板查看已学等级、上限与用途，看到被动属性变化，并保存/恢复学习结果。按共享学习链覆盖全部技能书，主动技能登记学习结果但不冒充已能战斗释放。

## 输入

- 依赖 TASK-ITEM-023。选择理由：物品成长之后，英勇之外20种技能书已注册但无学习入口；统一学习/被动属性是后续战斗的直接依赖。
- 有界调查：frame_9/DoAction.as:936–952 的职业/等级校验与整槽清除；2711–2732 的21项 allSkills 定义；2740–2776 addSkill 的首次学习、上限、XP启用；2806–2842 effect 的九种被动字段。
- 目录有21本技能书：战士9、法师9、公共3；12种主动/XP、9种被动。复用 role-skill-rules.ts、role-attribute-rules.ts 和持久字段字典。AS/P-code与注册可用，完整集合及恢复顺序在任务内核验。

## 范围

全部21本技能书共享学习，九种被动字段与人物属性重算；学习状态面板、关闭重开/切图/新建；完整存取/导入导出。替代英勇单项特例，保持既有接口兼容。主动技能施放、命中、快捷键拖放、被动战斗触发、商店购书是后续独立能力，不添加假战斗入口。没有正常材料入口的书用受控边界，普通路径用已有英勇书。

## 输出

docs/reverse-engineering/character-skills/ 源合同、冻结函数/哈希、验证；纯学习状态/规则、属性接入、技能面板和源字段所有权映射，领域与浏览器测试。

## 验收

- 独立源枚举对账21本书及21技能，无缺漏重复；冻结 addSkill/effect/useItem 的 AS/P-code 与原提取物一致。
- 两职业、职业不符、等级门槛、全部技能上限、首次/重复、单件/多数量整槽清除、旧按钮、死亡学习、XP首次启用与已有容量独立保留均与源oracle一致。
- 九个被动字段、两职业成长率、英勇/装备/戒指/超级球组合，属性最大值更新而当前生命不回满；战斗触发字段只记录不声称已产生命中。
- 两职业无probe正常新建、学习英勇、技能面板/属性、关闭重开、保存刷新及真实导入/备份恢复；受控全部书门槛与封顶、切图/新建重置；截图实际检查。
- 旧v1档推广学习字段不重放奖励，未实现raw保留，重复恢复不叠加属性。
- npm run typecheck、npm test、npm run build、npm run test:browser、npm run check:save；更新覆盖及下一合同，generate:harness/check:harness。

## 停止与拆分

先确认学习及持久字段真值再实现。真实缺失源输入或必须用户裁决时阻塞；不因复杂度拆成单本书任务。战斗释放与区域战斗另起完整合同，不混入本任务的完成声明。
