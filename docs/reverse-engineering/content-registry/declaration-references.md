# 声明引用的唯一性

任务与敌人的展示名称不是声明身份。相同任务标题可属于不同职业分支；同名敌人可出现在不同地图或同一地图的不同生成调用。

引用审计现在按源文件和行位置定位80条任务声明、227条敌人声明，再校验名称一致，每条必须命中唯一正式ID。此前按敌人名称查找使120处声明关联到多个生成记录；该歧义已修正。任务目标按名称匹配敌人时仍可关联多个生成记录，那是名称引用的集合语义，不能套用声明唯一性规则。

检查实现：`tools/lib/quest-reference-evidence.mjs`、`tools/lib/enemy-reference-evidence.mjs`。对应源测试逐条核对全部声明、同名分支和无效源位置。此项不证明全部调用引用或动态字段域审计完成；reference-audit状态继续保持进行中。
