# 城郊与城内往返覆盖

关闭证据：[源合同](../../reverse-engineering/city-roundtrip/source-contract.md)、[验证](../../reverse-engineering/city-roundtrip/validation.md)；双向源对照、两职业自然往返/两地真实存取、87全量浏览器及最终6专项通过。
