# 幻兽属性与评分

## verified

- `__Packages/HuanShouClass.as` 构造82、initialize810、checkUp1189、moreAttribute1261、flashAttribute1309；哈希及25种清单见 [source.json](source.json)。原始文件只读。
- 49个固定种子来自 `ITEM_PETS` 已验证注册；奇迹龙仅支持已具有完整数值的恢复记录，不在本项开放随机孵化。
- 主属性由物种 `max*Fen > 0` 判定。世代 `nowLifeLv` 将主属性最大成长率乘 `1.5 ** nowLifeLv`，最大评分加 `1000 * nowLifeLv`；不重复放大已经保存的实际成长率。罕见评分取物种下限和输入中的较大值。
- 四项评分为 `maxScore * (rate - maxRate / 2) / (maxRate / 2)`；副属性为0。零分母造成NaN写入时原setter忽略、未初始化codec读取0。总分是四项、罕见、转世×10、元素和称号之和。
- 元素、称号表消费既有独立源规则；未知称号源默认无，未知元素原类保留旧值、无法从种子可靠推断，现代详情明确不可计算。
- 属性先按元素百分比加成，再 `round(rate * (level + 5) * (1 + bonus * .01))`。
- `frame_9/DoAction.as:2643..2727` 显示星级为 `floor(allFen)/100`；成长率显示截至4位小数，各项评分和总评分向下取整。
- 铃铛须实际关联 `item.bell` 且battle为真才生效。背包、打造槽或全局持有的铃铛不是此关联。本次没有装备/出征操作，不凭持有或battle标记赋予收益。

## design 与字段归属

纯领域 `petDetails` 计算派生信息，不修改输入；初始凯恩HUD共用其生命上限计算。现代选择按钮和表格替代原粗糙面板。选择是瞬时对象引用，不保存；新角色/恢复更换owner后选择第一个对象，关闭后旧按钮不能操作。

持久记录拥有种子、可选世代/罕见/经验/旧等级/成长率/神状态等源字段；扩展记录显式值优先，缺失字段按相同原零基索引从raw推广。原零/false默认不额外添入已有稀疏记录，避免只读恢复改变对象形状。未知raw字段继续保留；不持久化派生评分，避免过期缓存覆盖真值。

现代数值继续使用明文，独立完整AS类oracle仅替换混淆codec为明文以验证数学语义。另保留真实codec边界回归：守护者等级150、水元素，原编码浮点误差得到2681生命，明文公式2682。该差异属于design，不宣称逐比特复刻。0..2以外世代与未知元素保留原字段并显示不可计算，不用猜测补齐。
