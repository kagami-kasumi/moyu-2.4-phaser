# TASK-PET-057 · 幻兽评称与名额持久化

## 目标
玩家为达到50星的幻兽评称，按物种剩余名额获得至尊、傲日、银月或罡星称号与转世上限提升，刷新或导入后不会重置名额。

## 输入
依赖TASK-PET-056。2327幻兽超进化frame1完整面板；frame9 DoAction_2:22 allTitle原始25物种顺序以及1623/2102保存读取；4312 cmd9331/9336白衣圣兽师评称入口；已有宠物详情、评分、保存raw/extension。选择理由：主属性与转世已贯通，补齐高评分养成的称号及独立持久名额，避免仅有titleNum字段而无玩家可用入口。

## 范围
所有25物种/49种子及奇迹龙；5000总分门槛、titleNum>0拒绝；从末尾查物种，剩余3/2/1/0对应5/4/3/2称号，正数才扣，最大转世+50，不消耗声明但未使用的price。未命中或异常名额保留源事实与现代拒绝边界。正常生命不因评称重置；出征/召回均能评称。独立名额表按原顺序保存、旧raw推广、未知值保留并禁止使用，不从宠物反推。现代设计：收藏详情提供评称快捷入口，服务可达性与原NPC位置分开记录，不宣称冰宫地图已实现。确认/取消/旧回调、跨图/新建、存读档。

## 输出
冻结源合同和独立oracle、名额与评称纯领域、收藏入口/预览、保存字段集成、两职业浏览器和旧档验证。

## 验收
全物种/种子、4999/5000与既有称号、名额3/2/1/0/异常、无匹配/重复匹配原源对照；实际费用零、上限+50、不同物种独立、第五只仍罡星、名额不重复消费。原allTitle25键及未知raw保留、三次codec、旧档缺失与坏值明确反馈。两职业正常低评分拒绝及受控高分四称号/保存恢复/导入、截图。typecheck、npm test、build、check:save、专项与成长回归、generate:harness/check:harness。

## 停止与拆分
评称、名额与存档为完整能力，不分技术阶段。冰宫地图、NPC社交不夹带实现。源异常不得当作正常奖励发放，须记录并保留未知原字段。
