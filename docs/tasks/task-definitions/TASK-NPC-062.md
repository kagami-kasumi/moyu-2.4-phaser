# TASK-NPC-062 · 皇宫宝箱抽奖与奖品使用旅程

## 目标
玩家在皇宫抽奖箱按原规则消耗灵魂晶石抽奖，获得完整奖池中的真实物品，能使用已有支持的奖品，并在保存恢复后保留消费与奖励且遵守读档等待。

## 输入
依赖TASK-WORLD-061；4536/frame1 npcState抽奖箱cmd10600、frame13位置；4312/frame1 DoAction cmd10600/10601；DoAction_2 luckyDraw及is5min完整函数；frame9创建物品工厂中的高级经验/攻击/减伤害/战斗力宝石默认字段；既有literalItem、背包扣除/满包掉落与完整codec。选择理由：皇宫访问后，邻接可独立交付的明确服务是抽奖箱；其40个奖池槽及物品生成规则能连接已有物品、幻兽和技能成长机制。

## 范围
完整四档40槽抽样、全部物品字段生成与随机调用顺序、单颗灵魂晶石消费、严格300000毫秒等待边界、新建免等待/读档重新等待的计时归属、确认取消/不足/满包与旧回调保护、奖品使用与跨区存取。其他NPC的luckyDraw1/2/3交换活动、社交、战斗任务与PK独立后续，不以本服务替代。

## 输出
独立源枚举及冻结函数、完整奖池与工厂转换、抽奖领域和界面、会话时钟边界、逻辑/浏览器/存取证据。

## 验收
源全集40槽和概率分段边界独立对照，四参数化宝石所有字段/随机顺序、两职业完整物品字段、无材料/不足等待/满包掉落/取消与旧按钮；两职业无probe从普通入口正常获取灵魂晶石、到皇宫正常抽奖，读档后等待、展示奖品与一次已有奖品用途、刷新和文件导入。受控覆盖全奖池与计时严格边界；读档不得绕过等待或重抽奖励。typecheck、npm test、build、check:save、抽奖专项及皇宫回归、截图、generate:harness/check:harness。

## 停止与拆分
奖池取证与生成不按阶段拆任务。未知物品工厂先保留证据并禁止扣除，不能缩减原奖池或替换成猜测奖励。其他NPC独立活动只登记后续。
