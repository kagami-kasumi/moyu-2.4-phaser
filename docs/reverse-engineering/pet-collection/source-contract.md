# 幻兽收藏整理与释放

## verified

原`frame_9/DoAction.as:2414..2508`定义40容量、四格显示、按battle/sortFen/sortLevels三项数值降序排序；afterAdd计算ceil(length/4)，show按(nowPage-1)*4截取，前后页有边界。

dropButton先打开确认消息，delHuanShou接收对象引用，从末尾查找同一对象并splice一次，之后刷新页和焦点。它不按种类名删除；原出征对象会先调用battle召回。本项独立执行上述sort/show/del函数与领域模型比较，而不是用运行时排序/删除生成expected。

## design

- 排序是只读投影，不改变存档数组，保持已有raw索引。完全同分同级采用稳定原顺序；不可计算评分排在同出征状态的已知评分之后，保留字段与详情提示。空集合显示1/1空页，避免原maxPage=0的无效导航。
- 释放限未出征对象：原版先召回的依赖尚未实现，因此battle=true明确拒绝，提示召回尚未开放。保护初始凯恩HUD，不假装已完成出征/召回或合体。
- 会话用对象引用和revision：更换选择/页、关闭/切图使旧确认失效；取消不改数据；重复确认只允许一次；删除末页会夹到最后有效页。新角色/读档更换owner，不沿用旧选择或确认。
- 显示现代四格导航、独立详情与明确不可恢复确认。释放是玩家在游戏中的明确操作，不自动删除收藏。

## 存档归属

`reward.petCollectionEdited`表示数组曾结构性删除，旧档省略时false。扩展数组保留每个对象及其未知扩展字段。读取时把活跃索引的未知raw后缀存入该记录的`sourceExtras`，不解释其内容。

结构性编辑保存时只重建原有效数量与当前数量所覆盖的索引区间：先清该区间旧键，再写各存活对象的sourceExtras、源声明缺省和自身持久字段。删除对象的键不转移给后继或新孵化对象；范围之外的未知raw（例如999号未来占位）保留。重复保存沿用已绑定对象的附加字段，不再猜测同名匹配。已知源字段不能通过sourceExtras覆盖。

不进行实际收藏排序时沿用既有保存路径；初始false标记不额外插入普通进度形状。原字段、未知值和完整codec由专项及保存回归验证。
