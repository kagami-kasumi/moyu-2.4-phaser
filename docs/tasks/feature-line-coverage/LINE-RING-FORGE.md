# 戒指打造覆盖

[TASK-EQUIP-029](../task-definitions/TASK-EQUIP-029.md)覆盖戒指品质0–4、八材料共享十级精炼、主副属性消费者、保存及所有权。输入已具有戒指与正常礼包材料。关闭须完整源字段与人物属性对照、两职业正常UI及存档旅程通过。其他饰品、材料获取与宝石融合不在本线。

关闭依据：[源合同](../../reverse-engineering/ring-forge/source-contract.md)、[验证](../../reverse-engineering/ring-forge/validation.md)，十材料、主副消费者与两职业持有/穿戴保存已覆盖。
