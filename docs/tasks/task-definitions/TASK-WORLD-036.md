# TASK-WORLD-036 · 城郊与城内持续往返旅程

## 目标
玩家进入卡萨诺城一后继续移动、访问商店，并能返回城郊使用管理员和老兵，再次入城；保存恢复后仍能往返。

## 输入
依赖TASK-NPC-035。选择理由：管理员交易和产权已成为城郊可用能力，现有首个旅程到城内即冻结移动、无法返回，阻断商店与城郊服务之间的自然循环。已有两地图资源与碰撞；源DefineSprite_4536/frame_8/DoAction.as:1–5、frame_9:1–5明确双向entry2↔entry1，frame_1:351–451为jumpMap/jumpToMap/allowJumpMap/afterJumpMap。现有first-slice冻结oracle可对照双向坐标和移动。

## 范围
开放现有两地区双向出口，移除“首段到达完成”对移动和入口的限制，保留complete为历史到达里程碑，避免破坏旧档。维护转场清地面掉落、关闭面板、释放输入，未知野外/城二区仍明确拒绝。新建/读档/同图状态刷新及两职业键鼠可用。

## 输出
双向源合同与冻结证据、旅程领域/输入/提示、回归与两职业无probe多次往返保存证据、覆盖台账。

## 验收
- 冻结AS/P-code对照双向目标/落点与城内移动/碰撞；远程、隐藏、零alpha、错误目标与未开放出口拒绝，拒绝不能部分改变地图或资产。
- 两职业正常步行/键盘出入城、杂货/药店→返回管理员与老兵→再入城；至少一次鼠标出口，长按Q不连跳。
- 往返保留背包/装备/爵位/产权与商店，清地面物品和过期回调；在城内和城郊保存、刷新及真实文件导入继续往返，旧complete=true档可移动。
- npm run typecheck、npm test、npm run build、npm run test:browser、npm run check:save；实际截图、generate:harness/check:harness。

## 停止与拆分
只解锁已具备证据与正式资源的两个地图，不新增野外、敌人、第三地图或传送道具。未知目的地保留不可用提示；不因单向首段已通过而把往返验收省略。
