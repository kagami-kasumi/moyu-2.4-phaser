# 出战幻兽经验

源HuanShouMC.as:433 expUp，正式规则src/content/pet-experience-rules.ts。未出战、生命恰好为0或等级已达到角色等级+10时直接退出。通过后奖励Math.round取整，再累加nowExp。

循环内先检查是否仍低于角色等级+10，允许时升1级并扣旧阈值；已经达到限制时把经验置为当前阈值减1。随后按新等级计算下次阈值：30/60/90/100以下分别等级乘9/15/30/72，110/120/130/140/150以下分别30000/40000/50000/60000/70000，其余80000。

仅当循环发生过时检查顿悟：新等级至少30且oldLevels更高，就直接恢复旧等级、旧当前经验和旧阈值，不重新检查角色等级差。之后刷新属性、填满生命、播放升级表现并刷新幻兽视图。通过入口检查的调用最后刷新血魔显示；拒绝入口不会刷新。

tests/pet-experience-source.test.mjs覆盖各阈值边界、达到领先上限后的溢出丢弃、三种拒绝入口，以及顿悟恢复到超过领先上限的旧等级。测试隔离该方法直接写入；属性setter、属性刷新和渲染内部规则单独核验。Infinity仅是正式表中最后兜底区间的上界标记，不是原版数值字段。
