# TASK-ITEM-011 · 月光宝盒装备开孔闭环

## 目标
玩家能将已领取或兑换的月光宝盒用于装备开孔，查看成功后的孔数；不满足条件时保留装备和宝盒，关闭、切图与满包不丢物品。

## 输入
- 前置 TASK-NPC-010 的宝盒兑换和 TASK-ITEM-008 的背包/装备。
- 根 `local-resources/moyu/source-index/as/scripts/frame_9/DoAction.as` make.setThing (2882)、flashInfo (2907)、yesButton.onRelease (3343)、useGem (3356)、makeItem (3384)，其中初/中/高级宝盒分支约3750起；对应 P-code 已有。
- `DefineSprite_4312/frame_1/DoAction.as` command case92 打造入口；以精确源索引继续定位 make 面板关闭/返还与 ThingMC 属性更新。
- 选择理由：兑换宝盒现只能查看；装备、宝盒和背包已齐备，开孔可把当前物品获取旅程接到实际装备变化。

## 范围
任务内完成源取证、独立冻结期望、纯规则用例、可见装备/宝盒选择与开孔反馈、逻辑和浏览器验收。覆盖三档月光宝盒的逐孔规则及实际允许装备类型，不扩展其他精炼、镶嵌、属性升级、战斗或存档。界面可按项目偏好重设计并标 design；关闭返还、物品所有权、重算与消息按源确认。

## 输出
`docs/reverse-engineering/equipment-sockets/` 源合同、独立基准和验证；领域/界面实现与逻辑、浏览器用例。

## 验收
- 冷启动获取可用装备，兑换宝盒后完成开孔，查看孔数及对应槽位值；装备其他属性不意外改变。
- 独立源期望覆盖三档宝盒、各孔数前置条件、允许/拒绝的装备类型、单个/堆叠材料消耗、失败不扣、重复/过期动作、装备与背包转移、替换材料、关闭重开、满包返还、切图与新建。
- 不以测试注入代替正常入口；正常冷启动链与受控边界均有浏览器操作和实际截图检查。
- `npm run typecheck`、`npm test`、`npm run build`、`npm run test:browser`，保持既有兑换/拾取/装备/地图和44动作回归；源解析或资源变化执行对应源门禁。
- 更新台账、调度并执行 `npm run generate:harness`、`npm run check:harness`。
