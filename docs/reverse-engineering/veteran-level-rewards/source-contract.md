# 030 老兵等级奖励源合同

## verified

`DefineSprite_4312/frame_1/DoAction.as:270–385`，cmd6提供8入口；cmd8以upLevelPrize*10严格小于人物levels开放，index<6 / <11 / 其余三个档位。初值1，因此首次须超过10级，150级最多领取140级档（index14），不能领取150级档。高等级仍按index一次一档补领，不自动跳级。

## design

奖励说明写“超过N级”并显示实际资源50000，修正文案与行为不一致，奖励数值不改。旧回调、关闭、切图、当前等级/索引不符时拒绝再发奖。现代存档拥有独立upLevelPrize并从旧raw推广，非法计数拒绝，其他raw保留。

## 范围

全部三档九奖励分支。正常旅程通过经验球成长和现有老兵接入，不增加战斗、远区、传送或其他NPC奖励。150级上限下未可达150档明确不开放。
