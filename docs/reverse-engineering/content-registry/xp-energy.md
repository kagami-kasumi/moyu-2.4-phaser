# XP 能量数值合同

已核验模块 `DefineSprite_4603/frame_1/DoAction.as`；正式目录为 `src/content/xp-energy-rules.ts`。这是数值注册，不是 XP 技能玩法已实现的声明。

初始化行1–13：能量0、容量3、容量顶限6、累计值0、每格阈值18，未激活、未满，六格均隐藏。

`addExp`（14–24）仅在已激活且未满时前置递增累计值；达到或超过18，先归零再调用 `powerUp`，溢出累计值丢弃。`powerUp`（25–40）先递增能量，未超过容量才显示对应格；恰好达到容量才设满。越界返回false，但递增不会回滚。`usePower`（41–51）仅在能量大于0时隐藏当前格、递减1、清除满标记，不清除累计值；零能量返回false且不修改状态。

外部调用语义：

- `frame_9/DoAction.as:2764`：首次学习震或怒时设置激活标记，受原技能等级上限分支约束。
- `__Packages/MonsterMC.as:416`：存活且攻击数值有效的受击处理，通过闪避判定后调用累计；零物理伤害也进入该分支。这不是击杀经验，后续元素伤害也不各自再调用一次。
- `__Packages/RoleMC.as:1459`、`:1756`：震与怒在非使用技能中且角色存活时尝试消耗1格；攻击效果成功不是扣格前提。
- `DefineSprite_4591/frame_1/DoAction.as:79`：能量药水仅在容量低于6时增加1并清除满标记，消耗1个堆叠；达到顶限时保留物品。容量比较不等于任意畸形输入的整数校验。
- `frame_9/DoAction_2.as:1611`、`:2090`：存取能量、累计值、满标记、激活标记、容量和六格显隐；阈值18、顶限6不存储。源恢复这些字段为直接赋值，不能用推算显隐覆盖已有源字段而声称完全相同。

独立源执行测试覆盖未激活、17→18、充满冻结、消耗后继续、零能量消耗、直接越界调用、累计值溢出。模块内的前置递增和后置递减由本合同明确登记，不能仅依赖赋值索引证明它们已覆盖。
