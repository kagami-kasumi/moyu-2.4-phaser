# TASK-PET-050 · 幻兽治疗与城郊复活

## 目标
玩家能给出征幻兽使用生命药或生命储备，并通过城郊管理员恢复人物和出征幻兽，死亡记录可重新获得经验。

## 输入
依赖TASK-PET-049。选择理由：已开放出征、生命持久化和死亡经验拒绝，但尚无恢复入口。DefineSprite_4556/frame_1/DoAction.as:96–119药品与生命之源分支；HuanShouClass.as:200生命setter；DefineSprite_4536/frame_1/DoAction.as:584–602 reLife；DefineSprite_4312/frame_1/DoAction.as:1581–1606管理员3000/3011。现有七药品目录、人物生命储备、出征槽与管理员交易。

## 范围
七药品按hpVal判定、源整格消费和生命封顶、储备不足/充足与不消耗容器、死亡拒绝；管理员免费恢复人物生命魔力及所有出征幻兽，未出征记录不改变。现代明确选目标与反馈，跨图/旧回调/存档归属。电浆药水、转世道具、战斗扣血和自动治疗不在本项。

## 输出
源合同、独立源oracle、纯治疗规则、收藏治疗入口与管理员复活按钮、两职业浏览器及存取报告。

## 验收
全部七药、血量0/缺血/满血、储备边界与2/3槽独立源比较；失败不扣物，重复/旧回调拒绝。两职业正常采购用药和管理员操作；明确受控死亡/储备/三槽导入后恢复、经验成长、刷新与实际导入，查看截图。typecheck、npm test、build、check:save、相关浏览器回归及generate:harness/check:harness。

## 停止与拆分
治疗复活整体交付，不按药品或技术阶段拆分；没有战斗扣血时受控伤亡必须如实记录，不伪装成自然战斗。未知幻兽属性保留并拒绝有歧义恢复。
