# 首个可玩闭环 · 覆盖合同

目标：基于真实启动与动作证据，接通一个最小玩家旅程。调度状态只在 [state.json](../state.json)。

本线范围固定为新建男战士、城郊地面移动/停步、通过城郊entry2到卡萨诺城一entry1的一次切图。入口关联见map/4536帧8脚本；几何、可见资源与边界条件在TASK-SLICE-004取证里程碑确认。不得扩展成战斗或全部系统。

关闭时需要：

- 从真实入口进入选定场景，执行一个可控操作并得到与原版有据对应的反馈。
- 该切片涉及的交互/命中/结果或重试逻辑有独立源证据与确定性测试。
- 画面使用选定范围内的原资源，输入、状态切换、失败/重试等合同状态全部验收。
- 明确记录缺口与切片边界；不称为“全游戏完成”。

选定旅程直接依赖的结果、敌人或流程机制取证，纳入 TASK-SLICE-004 的内部里程碑，先确认源证据再实现。只有超出单个旅程、可独立验收的能力才另立任务；不能一边猜测一边实现。
