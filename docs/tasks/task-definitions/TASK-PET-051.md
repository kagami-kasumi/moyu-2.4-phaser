# TASK-PET-051 · 三槽幻兽铃铛装备

## 目标
玩家能将三类铃铛放入出征槽装备位、替换和卸下，看到准确属性和战斗力；召回换兽时装备留在原槽，并完整存取。

## 输入
依赖TASK-PET-050。选择理由：幻兽出征/成长/治疗已可用，而原版三槽铃铛尚只可持有与兑换；接通既有装备持有物的真实消费者。frame_9/DoAction.as:2343–2413三套setThing/notice；DoAction_2.as:180–185面板绑定、881起huanShouItem保存及对应恢复；HuanShouClass.as:1250–1316元素与铃铛属性；4556/frame1:42–65评分与grade+1；三类铃铛工厂种子及现有物品/保存注册、backPack.setThing满包掉落。未开放自然掉落需如实使用受控来源。

## 范围
三种铃铛、全部品质可激活的1..3属性槽、与元素叠加、人物总战斗力；三独立活动装备位，换兽/召回留槽、替换/取回/满包掉落、生命最大值与卸下钳制顺序；保存raw拥有者和旧档推广，未知字段保留。铃铛打造、战斗触发技能和合体不在本项。

## 输出
源合同与独立对照、纯铃铛所有权规则、可操作三槽UI、属性消费者与保存扩展、两职业验证。

## 验收
三类型×品质×属性×元素×49种子独立源对照；原面板接受域/替换顺序、全槽/死亡/未知、旧回调、召回换兽/释放后留槽；真实codec及旧raw。两职业受控铃铛入包后正常装备/替换/卸下/经验与治疗消费者/切图/刷新和实际导入，截图检查；自然获取缺失不伪装。typecheck、npm test、build、check:save、相关浏览器回归、generate:harness/check:harness。

## 停止与拆分
完整三槽装备能力交付，不按铃铛类型或取证阶段拆任务。未知铃铛字段保留并拒绝装备，不能由背包持有推定已装备。
