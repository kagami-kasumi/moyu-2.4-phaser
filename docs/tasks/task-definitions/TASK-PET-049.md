# TASK-PET-049 · 幻兽出征召回与经验球成长

## 目标
玩家能将已孵化幻兽出征、召回并分配普通经验球，看到准确的等级、生命、经验和属性变化；收藏释放、切图和存档恢复保持同一对象与活动槽位。

## 输入
依赖TASK-PET-048。选择理由：已完整孵化和整理收藏，但初始battle记录不能操作、成长入口只支持人物；补齐有据的出征生命周期才能消费全部幻兽并解除释放保护。frame_9/DoAction.as:2509起battle/inOne与集合；DefineSprite_4556/frame_1/DoAction.as:10..100的open/flashView/flashAttribute/close/useExpball，348起按钮；__Packages/HuanShouMC.as:433 expUp及battle/reBattle生命周期；DefineSprite_2181_使用经验球/frame_1/DoAction.as整段选择/自动出征/确认链；frame_9/DoAction_2.as:1637/1766的maxBattleNum保存恢复。既有pet-experience-rules与独立源测试、046属性、047初始化、048收藏身份、PlayerExperience与当前原HUD资源（4556）。

## 范围
有据活动槽位与上限、出征/召回、选择目标普通球2000经验、全部阈值/人物等级领先10/顿悟旧等级、属性与生命回满、HUD和收藏状态、旧档字段归属与切图/新建。原出征身体生命周期须先取证；原生呈现方案可design，不能只改battle布尔就宣称出征已完整。未知铃铛归属不得凭持有添加收益。敌人战斗、主动技能、幻化/世代提升、成神和铃铛装备操作不在本项。

## 输出
源调用与槽位/生命/经验合同、独立源oracle、纯出征成长领域、原生可观察投影、人物/幻兽经验选择UI、完整存取及两职业验证报告。

## 验收
- 所有已注册物种使用同一有据生命周期；原槽位上限/自动出征/释放召回顺序和角色战斗力消费者有独立对照。
- 经验阈值全部边界、死亡/未出征/等级领先拒绝、顿悟突破领先限制、回满和单颗扣除；旧按钮/取消/换目标、同名不同记录、切图/刷新不重复收益。
- 两职业无probe正常购买/孵化/出征/分配/召回/释放、人物与多幻兽切换、保存刷新和实际文件导入；受控上限/死亡/旧档与未知输入，实际查看截图。
- typecheck、npm test、build、check:save、相关浏览器回归、generate:harness/check:harness。新增资源转换另执行其独立像素/绑定门禁；不能用构建代替可观察生命周期。

## 停止与拆分
以可操作出征和消费普通经验球的完整旅程交付；不按物种或逆向/实现阶段拆分。缺失源生命周期或槽位关联的真实事实才阻塞，保留未知字段并拒绝有歧义的操作；不得以假召回解除048保护。
