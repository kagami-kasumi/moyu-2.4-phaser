# TASK-PET-056 · 幻兽转世幻化

## 目标
玩家在城三幻化师处选择幻兽，以灵魂晶石完成转世幻化，并按原顺序选择自动经验球，获得可保存的转世和等级变化。

## 输入
依赖TASK-PET-055。源2344转世幻化面板frame1完整函数；4312 cmd113/115；HuanShouClass.turned/checkUp；4556经验球；现有出征、槽位铃铛及保存。选择理由：主属性幻化与转世丹已接通，补齐同一NPC剩余核心养成服务，转世幻化拥有不同消费顺序，必须独立可观察验收。

## 范围
49固定种子与奇迹龙；选择时出征；转世上限先于自动球；自动球在30级及灵魂晶石检查之前，可在最终失败时仍合法消费；一晶石、一次转世、评分+10、降级、旧等级快照、最终生命恢复。完整预览明确部分消费，确认/取消/重复旧回调、切图/新建、保存恢复。无副兽和草，不改变成长率。称号及合体战斗另属任务。

## 输出
冻结源和独立oracle、纯领域、正式NPC入口和预览、两职业自然获取材料与受控边界浏览器验证、源合同和验收记录。

## 验收
全部49种子和奇迹龙、等级29/30、转世上限、两球不足/死亡/人物限制、先用球后缺晶石失败与成功逐状态源对照；旧等级恢复、铃铛归属、重复确认、切图新建及真实codec往返。两职业正常灵魂礼包拆包/成长/转世/保存导入与受控异常。typecheck、npm test、build、check:save、浏览器专项与相关回归、截图检查、generate:harness/check:harness。
