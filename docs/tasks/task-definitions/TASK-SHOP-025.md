# TASK-SHOP-025 · 城内杂货商购买与出售机制包

## 目标

玩家到卡萨诺城一与杂货商交易，选择数量购买当前开放商品、出售背包物品，看到真实余额/库存变化并保存恢复。交付共享交易机制与完整杂货目录，不逐商品建任务。

## 输入

- 依赖TASK-SKILL-024及既有背包、掉落、保存。选择理由：成长/学习完成后，现有旅程仍没有可持续采购/出售入口；城内已显示杂货商奈奈安，补交易可连接现有打造和库存周转，不造奖励来源。
- 有界源调查：DefineSprite_4536/frame_1/DoAction.as:172定义杂货商奈奈安、卡萨诺城一、jobLevels1/cmd71。DefineSprite_4312/frame_1/DoAction.as:case71/72提供对话/打开shop，case8402职业升级修改开放数量，升级属于邻接NPC成长。
- frame_9/DoAction_2.as:187、196–199、212–215定义杂货商16条saleThings、初始openNumber4和等级开放表[0,4,7,10,13,16]。1485/1951保存恢复shop.openNumber。
- DefineSprite_2089_幻兽商店/frame_1/DoAction.as的open/sell/onSell/setThing是共享普通商店候选，须由SWF实例/脚本绑定证明shop实际使用它，不能仅凭相似名字套用。买入先检至少一空槽，再按店面salePrice×数量付款、逐个createThing；卖出floor(salePrice/2)×数量，完整字段与异常语义须冻结验证。
- DefineSprite_167_输入数量/frame_1/DoAction.as数量1–99、四舍五入、重复打开同项可能切99；frame_9/createItem、backPack及源货币setter是后续完整物品入包/掉落/封顶真值。全部AS/P-code和SWF可用。

## 范围

完整16条杂货目录（含不同参数宝石）的源对账、交易规则、NPC入口、数量/确认/取消、购买与出售、货币/库存/掉落/保存。正常路径只开放源当前数量，受控验证其余解锁档位，不能为展示打开全部商品。只接当前可达地图的真实杂货商。

药店、技能导师书店、幻兽店、资源币城堡店及商人职业升级为独立NPC/区域后续；共享交易代码须便于复用，但不伪造这些NPC在当前地图的入口。不得把商店标价误写成createItem默认售价；不得自动出售玩家物品。

## 输出

docs/reverse-engineering/ordinary-shop/ 源合同/冻结oracle/目录覆盖/字段映射/验证；交易领域模块、城内NPC与商店面板、保存扩展、逻辑及浏览器检查。现代面板外观可design，原素材只读。

## 验收

- 16条有序货品与独立源数组/注册精确对账，参数宝石保留val1/val2；AS/P-code哈希与真实实例绑定核验。
- 源oracle核对数量1/99/小数/NaN/上下界、同商品重复选择、空槽门槛（满包即使可堆叠）、单/多件、部分入包与溢出、余额不足/恰好/封顶、按店面价扣款和工厂价保存、出售0/无售价/数量0/多堆/装备，拒绝过期按钮与切图后的交易。
- NPC对话只开放交易所需源分支，保持老兵已实现分支；两职业无probe新建→城内→正常腾格/购买→使用或打造→出售→存取，不能使用假资金或假商店入口。
- 存档/刷新/真实导入备份恢复保留余额、物品全字段、解锁数及未实现raw，无交易重放；关闭重开、取消、切图、新建状态验证。受控不足/满包/不同开放数截图实际检查。
- npm run typecheck、npm test、npm run build、npm run test:browser、npm run check:save；如解析/提取工具变化另check:source；更新覆盖和下一合同，generate:harness/check:harness。

## 停止与拆分

先确认shop绑定、源条目生成与收付款顺序再实现。只因真实源材料缺失或必要用户裁决阻塞；不因条目数或取证阶段拆分。区域NPC/商人升级/其他货币商店归后续完整能力，不在本任务冒充完成。
