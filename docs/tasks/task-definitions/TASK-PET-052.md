# TASK-PET-052 · 铃铛双槽融合打造

## 目标
玩家能将两枚同品质铃铛放入独立打造槽，预览并确认融合，得到有据的品质、纯度、属性和技能结果，再装备或取回；关闭、切图与存档保持持有物。

## 输入
依赖TASK-PET-051。选择理由：已接通三类铃铛装备和全部属性消费者，但品质和副属性还不能通过玩家操作提升。frame_9/DoAction.as:4003–4139 makeBell.setThing/notice/flashInfo/makeItem/yesButton；upDataWeapon铃铛分支；2049/frame1 upData调用；DoAction_2 makeBell_item1/item2保存恢复；注册铃铛种子及现有双槽宝石融合所有权模式。

## 范围
三铃铛类型、相同品质0..3融合至4、异类型也可融合但纯度仅同类累加、grade2第二属性抽签/grade4第三属性补齐、grade4纯度16且skill0的两技能随机、精确随机次序、更新attributeVal与售价。双槽放入/替换/取回/满包、预览确认、旧回调、存取与旧raw；技能值只保存展示，不冒充战斗触发。自然掉落仍另属区域战斗任务。

## 输出
源合同/冻结函数/独立oracle、纯融合领域和UI、双槽保存归属与两职业验证。

## 验收
三类型有序组合×全部品质边界×纯度×随机分支独立源对照，费用无虚构、失败零消费、第二槽只清一次、所有输出属性与纯度技能。两职业明确受控铃铛后正式UI完整融合/装备/取回/满包/切图/刷新及实际导入；截图检查。typecheck、npm test、build、check:save、相关浏览器回归、generate:harness/check:harness。

## 停止与拆分
