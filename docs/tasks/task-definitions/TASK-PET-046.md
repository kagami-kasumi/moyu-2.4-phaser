# TASK-PET-046 · 幻兽属性与评分详情

## 目标
玩家能从幻兽记录选择已拥有的幻兽，查看有据的生命/攻击/防御、成长率、评分与星级，比较购买和任务奖励的幻兽；保存恢复保持同一对象及源字段。

## 输入
依赖TASK-SHOP-045。选择理由：城三交易和升级已提供多类幻兽，当前面板只显示初始种子，无法比较实际属性；先完善整个幻兽属性域，作为后续经验成长/出征/幻化的消费者。原__Packages/HuanShouClass.as构造、initialize:810、checkUp:1189、flashAttribute:1309及属性/评分accessor；frame9/DoAction.as约2643幻兽信息消费者；已注册pet-score-rules、pet-attribute-rules、pet-initialization-rules与全部物种参数，tools/lib/pet-initialization-oracle及独立pet-score/attribute源测试。当前PetRecord、ITEM_PETS、宠物raw持久字段和HUD来源。

## 范围
全部现有固定种子变体与可恢复幻兽记录的统一属性/评分计算、元素/称号/转世/世代的有据贡献、详情选择与HUD初始幻兽一致性、字段归属和旧档无损恢复。不存在的输入不能补成原版事实；铃铛条件需按源区分已有持有与实际生效，未开放出征/合体不得制造收益。随机奇迹龙孵化、战斗、经验消费、幻化与装备操作仍为后续能力。

## 输出
源字段/公式合同、独立全物种及变体对照、纯领域属性模型、可见详情面板和存档推广、两职业浏览器及验证报告。

- 两职业无probe城三购买/领奖并孵化，选择不同幻兽看到可比较属性和评分；保存刷新与真实导入一致，选择/关闭/切图/新建不改错对象，原人物HUD/商店/升级回归。
