# 幻兽出征与经验成长覆盖

[TASK-PET-049](../task-definitions/TASK-PET-049.md)负责有据活动槽、出征召回、普通经验球分配/所有阈值/顿悟、HUD及可观察原生生命周期、收藏解除保护、完整存档。槽位上限、自动出征和原身体生命周期必须取证，不能只改布尔值宣称完成；敌人战斗、主动技能、幻化/世代、成神与铃铛装备另属后续。

已验证出征、召回、经验球与顿悟、同名槽位、原HUD和现代随行投影、存档与两职业旅程，见[源合同](../../reverse-engineering/pet-progression/source-contract.md)及[验证](../../reverse-engineering/pet-progression/validation.md)。本线范围闭合；生命恢复、装备、合体和战斗由后续独立能力承接。
