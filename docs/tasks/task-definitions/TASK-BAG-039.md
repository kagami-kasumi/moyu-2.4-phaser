# TASK-BAG-039 · 54格仓库存取与旧档恢复

## 目标
玩家将背包整格物品存入54格仓库，再取回使用；装备、宝石参数、材料堆叠和未实现旧档物品均跨地图与存取保持所有权。

## 输入
依赖TASK-GEM-038。选择理由：已解锁全杂货和融合会增加实际背包压力，仓库已经注册54槽及全部原持久字段，可补齐物品保管链。frame_9/DoAction.as:1725起wareHouse.setThing/notice/initData、backPack.setThing和mover交接；frame_9/DoAction_2:690保存与1811恢复；4312/frame1 cmd153原军团管理员入口；ThingMC数量/room/addNumber。

## 范围
固定54槽，自动按源顺序合并/寻找空位，整格存入/取回，部分合并后剩余保持原位，满仓拒绝、满背包取回按既有掉落规则处理；源字段迁入/回写与未实现内容保留。背包直接仓库按钮为design，延续现代打造入口；不声称军团管理员/城二区已开放，不引入容量购买或全局拖放。

## 输出
完整源证据、仓库领域及界面、54槽保存消费者、独立源oracle、两职业正常存取与真实导出导入、截图和覆盖台账。

## 验收
- 独立源对照空槽/满槽、数量0/1/98/99和多格合并、同类型不同名称、名称缺省、全字段保留、部分入仓与余量，无复制或丢失。
- 两职业无probe存入材料/装备或戒指、查看仓库、取回及可用入口、切图、刷新和真实导出导入；受控满仓、满包落地、旧按钮和新建重置。
- 旧raw的全部54槽按独立编号恢复；未知物品保留并占位，不能被普通存入覆盖；无当前可执行数据的raw仍保留。
- npm run typecheck、npm test、npm run build、npm run test:browser、npm run check:save、generate:harness/check:harness；实际查看截图。

## 停止与拆分
存入/取出/持久化是同一能力，不能分阶段虚标完成。原版交接异常按证据记录并明确现代恢复策略；只有实际缺少输入或用户裁决才阻塞。
